# Marcenaria 3D — GLB + Materiais + Transformações

Versão web para GitHub Pages. Importa GLB/GLTF, aplica materiais/texturas e permite mover e rotacionar objetos com controles 3D ou campos numéricos.

- **Mover**: selecione o objeto, toque em Mover e arraste as setas X/Y/Z.
- **Rotacionar**: toque em Rotacionar e arraste os arcos.
- Também é possível informar posição X/Y/Z e rotação Y em graus.
